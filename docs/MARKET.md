## 最終判定: 売れる

**Claude としての最終判断（2026-06-11、製品側ブロッカー解消後に確定）: 推奨戦略（$19 買い切り・英語圏・Paddle 直販）で出せば、Pomo は売れる。**

- 「売れる」= 売上が立つこと。これは当時の判定。同一の開発者層・同価格帯で LookAway が 4,000 本売った実証テンプレートがあり、Pomo にはフローモード × 全Space/フルスクリーン追従 × 履歴を持たない軽さという差別化がある
- 「儲かる」とは区別する。初年度中央値は ¥15万〜80万、期待値 約¥50万。時給換算では割に合わない。価値の本体は売上＋Swift 出荷経験＋ポートフォリオの合算
- 判定を覆す条件も明記する: 需要検証（デモ動画）の反応がゼロ署名なら撤退基準どおり無料/OSS 路線へ転換する。それでもこの判定（=製品と戦略の妥当性）は「売り方を変える」だけで無価値にはならない
- 会議・通話中のオーバーレイ自動延期は実装済み。APIは2026-06-13に、記録機能は2026-08-20に廃止済み

## 推奨戦略

| 項目 | 推奨 | 根拠 |
|------|------|------|
| 価格 | **US$19 買い切り**（¥2,980）、14日トライアル | LookAway の実証価格。¥300帯は monora が実証した死路。サブスクは無料競合と正面衝突 |
| チャネル | **Developer ID + 直販（Paddle）先行** → 3-6ヶ月後 Setapp 申請 → MAS は後追い任意 | Setapp は Session の実測で収益の25〜75% |
| ローンチ | **Show HN + Product Hunt、「履歴を持たず今だけに集中するフロータイマー」の角度** | 日本語圏中心なら monora の再現になる |
| 収益見込み | 下振れ ¥0〜10万 / 中央 ¥15万〜80万 / 上振れ ¥150万〜500万（HN ヒット or Setapp 採択時） | 買い切りは2年目に構造的逓減。Setapp か有償アップグレードで対策 |

## 売る前の絶対条件（P0）

1. ✅ **会議・通話中のオーバーレイ自動延期**（CoreAudio マイク監視、権限プロンプト不要、トグルでOFF可）
2. **需要の事前検証**: 4モードとフローティング挙動のデモ動画を X/HN に出す。反応が閾値未達なら販売を中止し「無料/OSS + ポートフォリオ」路線へ転換する**撤退基準を先に決める**
3. Xcode プロジェクト化 + Developer ID 署名 + notarytool 公証（Apple Developer Program $99/年 — ご主人様の支出判断が必要な唯一の項目）
4. Paddle 開設 + ライセンスキー + トライアルロジック
5. Sparkle 自動更新
6. UI 英語化 + 英語 LP + デモ動画

## 技術判定

- **計測データを保存しない**: 作業時間はメモリ上の今回だけ。JSONL・SQLite・DB・外部連携を持たず、UserDefaultsは設定だけに使う
- **MAS 適合**: 計測データの外部ファイルアクセスやlocalhost APIを持たないため、記録機能由来のSandbox境界問題はない

## この判定が破綻しうる条件

- 需要検証（デモ動画の反応）が閾値未達 → 即「無料/OSS」路線へ。この場合も Swift/出荷経験という投資回収は成立する
- 「履歴を持たない軽さ」が弱い訴求に留まる場合、フローティング挙動とフロー体験だけで差別化できるかを再検証する
- 英語圏ローンチに必要な英語での発信・サポートのコストを負えない場合、中央値はさらに下がる
