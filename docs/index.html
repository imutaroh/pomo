はじめての開き方

無料配布のため、初回だけ手動で開きます。

  1. ダウンロードした .dmg を開き、中のアプリを「アプリケーション」へドラッグ
  2. ダブルクリックで起動。「悪質なソフトウェアがないか確認できない」と警告が出たら、「完了」を押す（ゴミ箱には入れない）
  3. システム設定 → プライバシーとセキュリティ を開き、下へスクロールして「このまま開く」→「開く」
  4. それでも開けないときは、ターミナルに1行：
    xattr -dr com.apple.quarantine /Applications/Quiet.app
    v0.9.3 以前をお使いの方は、末尾を Pomo.app に読み替えてください
  5. 起動すると、メニューバーと Dock にアイコンが表示されます

Apple の公証(notarize)を行っていないための手順です（macOS 13 以前は右クリック→「開く」でも開けます）。会社支給などの管理対象(MDM)Macでは起動できない場合があります。v0.9.3 以前からアップデートした場合、アプリの中身は Quiet になりますが、アプリケーションフォルダ上の名前は Pomo のまま残ります（自動アップデートの仕様です）。
