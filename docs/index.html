( 01 / erased )

01.

消したもの、残したもの

集中を助けるはずのタイマーに、いつのまにか集中を邪魔するものが増えていました。Quiet は、足すのではなく消すことで作っています。

消したもの残したもの

  1. 消したもの：25分で鳴るベル

    →

    区切りは、自分で決める。

    フローモードは経過時間を数えるだけ。乗っているあいだは邪魔をせず、止めたところで休憩の長さを出します。

  2. 消したもの：日別・週間の集計、セッション数、ストリーク

    →

    今回の時間だけ。

    履歴を持ちません。アプリを閉じれば、今回の時間も消えます。昨日の自分と比べられることはありません。

  3. 消したもの：「今日は何分できた？」

    →

    看守ではなく、秘書。

    強制せず、提案する。罪悪感を煽りません。上限のリマインドは止めずに知らせるだけ。休憩にも、延ばす・小さくする・飛ばすの逃げ道があります。

  4. 消したもの：画面を占領する窓、フォーカスを奪う入力欄

    →

    端に浮かぶ、小さなパネル。

    すべての Space、ほかのアプリのフルスクリーンの上にも浮かびます。入力欄を置かないので、キーボードはいまの作業のまま。

  5. 消したもの：アカウント、テレメトリ

    →

    この Mac の中だけ。

    通信するのはアップデートの確認とダウンロードだけ。作業時間も利用データも、どこにも送りません。

( 02 / presence )

02.

浮かんで、透けて、邪魔をしない。

パネルは、あなたとの距離で姿を変えます。触れたいときだけ現れて、計測中は背景に馴染む。下の模型は実物と同じ大きさです。

フルスクリーンのエディタ

集中 · 不透明度 30%（既定・変更可）

集中
18:20

パネルにカーソルを乗せてみてください。少し待つとボタンが押せます。休憩のピルを押すと、休憩画面に入ります。

  • 操作乗せると、操作がすべて現れる
  • 待機何もしなければ、数字と進捗バーだけ
  • 集中計測中は透けて、背景に馴染む

  • 操作
    マウスを乗せると、操作がすべて出る開始・一時停止・リセット・休憩へ。ボタンはホバーが少し続いてから押せるので、通りすがりのクリックで止まりません。
  • 待機
    何もしないと、数字と進捗バーだけ読むべきものしか置きません。
  • 集中
    計測中は、パネルが透けて背景に馴染む不透明度は設定で変えられます。マウスを乗せれば、すぐ戻ります。
  • どこでも
    全 Space、フルスクリーンの上にもキーボードのフォーカスは奪いません。入力欄を置かない設計です。
  • キー
    ⌃⌥P 開始 / 一時停止
    ⌃⌥T パネルの表示 / 非表示    メニューバーに常駐し、Dock にも出ます。設定・願い・仕組みのページは、別の母艦ウィンドウにまとめてあります。

( 04 / break )

04.

休むときは、画面ごと休む。

休憩は、通知を閉じて終わりにしない。つながっているすべてのディスプレイが「ひと休み」に切り替わります。それでも、閉じ込めはしません。

  • 全画面
    全ディスプレイを覆う、全画面の休憩画面今回の集中時間を添えて表示します。
  • 逃げ道
    +5分 / 小さく / スキップ延ばすことも、小さくしてそのまま続けることも、飛ばすこともできます。
  • 入力
    クリックは遮る。キーボードは奪わない打ちかけの文字が、よそへ飛ぶことはありません。
  • 会議中
    マイクを使っているあいだは、全画面にしない会議や通話の最中は、全画面化を見送ります。
  • 合図
    終わったら、音とシステム通知で知らせるパネルを見ていなくても、区切りはわかります。

( 05 / nothing )

05.

数えない。比べない。残さない。

  • 日別・週間の集計持たない
  • セッション数持たない
  • メモ・検索持たない
  • ストリーク持たない
  • アカウント持たない
  • テレメトリ持たない
  • 設定これだけ保存する

記録を持たないから、送るものもない。

Quiet は、あなたの Mac の中だけで動きます。外と通信するのは、新しい版があるかの確認とダウンロードだけ（GitHub 上の更新情報を取りにいきます）。作業時間や利用データは、どこにも送りません。

新しい版が見つかると、アプリがお知らせします。入れるかどうかは、あなたが決めてから。

無料で、ソースはすべて GitHub で公開しています（MIT ライセンス）。

( 06 / faq )

06.

よくある質問

いつ使えるようになりますか？

いま、公開に向けて準備しています。使えるようになったら、このページでお知らせします。無料で配る予定です。

記録が残らないのは、不便ではありませんか？

記録やグラフを見ること自体が、集中の妨げになることがあります。Quiet が見せるのは「今回どれだけやったか」だけです。日別・週間の集計、セッション数、メモ、検索、ストリークはありません。保存するのは設定だけで、アプリを閉じれば今回の時間も消えます。

通知や音は出ますか？

出ます。終わったときに、音とシステム通知で知らせます。休憩は全画面の休憩画面になります（マイク使用中は全画面化を見送ります）。

どんな通信をしますか？

アップデートの確認とダウンロードだけです（GitHub 上の更新情報を取得します）。作業時間や利用データはどこにも送りません。アカウントもテレメトリもありません。

アップデートは勝手に入りますか？

いいえ。アプリが新しい版を確認してお知らせし、あなたが承認するとインストールされます。

Intel の Mac で使えますか？

使えません。Apple Silicon（M1 以降）、macOS 14 以降の専用です。
